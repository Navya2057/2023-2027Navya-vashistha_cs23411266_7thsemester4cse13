🇮🇳 Indian Startup Funding Analysis

📌 Project Overview

This project focuses on analyzing funding trends in the Indian startup ecosystem using data analysis and visualization techniques.

The analysis explores startup funding patterns, funding amounts, industries, locations, and other factors to identify meaningful trends and insights from the dataset.

«Note: This project was independently created as part of my learning and portfolio development, inspired by the type of data-analysis work performed during a Deloitte Virtual Internship.»

---

🎯 Objectives

- Analyze funding trends across Indian startups
- Identify industries receiving the highest funding
- Understand funding distribution across different cities
- Explore startups receiving significant investments
- Analyze funding patterns over different years
- Identify key trends and insights from the dataset
- Practice data cleaning, exploratory data analysis, and visualization

---

🛠️ Technologies Used

- Python
- Pandas – Data manipulation and analysis
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical visualization
- Jupyter Notebook

---

🔍 Analysis Performed

The project includes:

1. Data Cleaning
   
   - Handling missing values
   - Removing/handling duplicate records
   - Cleaning inconsistent data formats
   - Converting funding-related values into usable formats

2. Exploratory Data Analysis (EDA)
   
   - Year-wise funding analysis
   - Industry-wise funding analysis
   - City-wise startup analysis
   - Funding amount distribution
   - Top-funded startups

3. Data Visualization
   
   - Bar charts
   - Line charts
   - Distribution plots
   - Comparative visualizations

4. Business Insights
   
   - Identification of highly funded sectors
   - Major startup hubs in India
   - Funding trends over time
   - Patterns in startup investments

---

📊 Key Insights

Some of the major insights derived from the analysis include:

- Certain industries attract significantly higher investment than others.
- Major metropolitan cities act as important startup and funding hubs.
- Startup funding varies considerably across different years and sectors.
- A relatively small number of startups account for a significant portion of the total funding.

Detailed findings and visualizations are available in the Jupyter Notebook.
